# Current state

As of November 2026 the repository is a public, account-free study dashboard.

## What exists

- `src/routes/index.tsx`: the dashboard. It lists three subjects, filters them by search, switches between day and night themes, runs a 25-minute focus timer, and opens a guidance dialog. All of it is temporary browser state.
- `src/routes/__root.tsx`: HTML shell, title, description, and favicon.
- `src/styles.css`: Tailwind setup, glass styling, and the day/night palette driven by CSS variables and the `.night` class.
- `src/components/ui/dialog.tsx`: Radix Dialog used by the guidance modal.
- `public/labs/`: three standalone HTML labs with their original lessons and simulation logic.
  - `waec-maths-dashboard.html`: Mathematics syllabus and simulations
  - `physics_lab_full.html`: Physics canvas simulations
  - `chemistry-simulations.html`: Chemistry topics and simulation modules
  - `glass.css` and `glass.js`: shared navigation, theme toggle, and keyboard access
- `netlify.toml`: rewrites the original lab paths (`/waec-maths-dashboard`, `/physics_lab_full`, `/chemistry-simulations`) onto the files in `public/labs/`.

## Stack

React 19, TypeScript, TanStack Start and Router, Vite, Tailwind CSS 4, Radix UI, Lucide icons, hosted on Netlify (Node 24).

Local development:

```sh
pnpm install
netlify dev --port 8889
```

Route types are generated by the TanStack plugin. Do not edit `src/routeTree.gen.ts`.

## What is missing for schools

- No user accounts, sign-in, or roles.
- No database. Nothing about a learner is recorded.
- The labs are static HTML. They do not report which lesson or simulation was used.
- No tasks, submissions, or teacher views.
- No school, campus, license, or seat concept.
- No way to package the app for a school server or manage it remotely.
- The lab HTML contains Netlify deploy scripts (`/.netlify/scripts/ar` and `/.netlify/scripts/hud`). Remove them from the campus build, since campus servers are not Netlify and student devices are offline.
