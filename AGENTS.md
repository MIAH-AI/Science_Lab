# Learn with Nehy

## Architecture

This is a React 19 / TypeScript application using TanStack Start, TanStack Router, Vite, and the Netlify Vite plugin. The landing page is a WAEC learning workspace with locally hosted copies of the original study labs. No learner records or accounts are stored.

## Key directories

- `src/routes/index.tsx`: study dashboard, subject catalog, transient theme and navigation state, subject search, and focus timer.
- `src/routes/__root.tsx`: HTML shell, providers, page title, description, and favicon.
- `src/styles.css`: Tailwind setup, shared UI tokens, bespoke glass styling, day/night colors, and responsive layouts.
- `src/components/ui`: available Radix-based shared components. The guidance modal uses the accessible Dialog primitive.
- `public/labs/`: standalone subject labs, shared glass styling, and accessible theme/navigation controls.
- `public/favicon.svg`: custom graduation-cap brand mark.
- `netlify.toml` and `vite.config.ts`: hosting and framework configuration.

## Conventions and decisions

Use typed React components, semantic HTML, accessible icon-button names, visible keyboard focus, and reduced-motion overrides. Keep colors themeable through CSS variables. The workspace's `.night` class controls the dark palette. CSS/SVG artwork replaces raster imagery intentionally to match the sculpted reference aesthetic without showing screenshot chrome.

Subject URLs and syllabus counts come from the original Learn with Nehy landing page. The three labs are migrated into public/labs with their original lessons and simulation logic. Netlify rewrites preserve the original lab paths. Shared glass.css and glass.js provide default/night styling and navigation; keep the source simulation logic intact. Do not invent learner progress or completion statistics. The focus timer and selected appearance are temporary browser UI state; persistent application data must use Netlify platform storage.

Use `pnpm install` and `netlify dev --port 8889` for local development. Route types are generated by the TanStack plugin; do not edit generated route-tree files. The managed build pipeline handles production validation. Do not run build, test, type-check, or dev-server commands during managed agent runs when the platform forbids them.
